# CS330 3D Graphics Project

## Overview

This project was created for CS330: Computational Graphics & Visualization at Southern New Hampshire University

The goal of the project was to build a 3D scene using OpenGL and apply concepts such as lighting, textures, transformations, and scene composition. Through this project, I gained hands-on experience with graphics programming and a better understanding of how 3D environments are created and rendered. 

## Technologies Used
-: C++
-: OpenGL
-: GLFW

## Skills Demonstrated
-: 3D Graphics Programming
-: Object Transformation
-: Lighting & Materials
-: Texture Mapping
-: Scene Design
-: Problem Solving

## What I Learned

Working on this project helped me better understand how objects are positioned and transformed within a 3D space. I also learned how lighting and textures can improve the look and realism of a scene.

One of the biggest takeaways was learning how many small components work together behind the scenes to create a complete 3D environment
